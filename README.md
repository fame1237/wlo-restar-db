# ปีศาจรีไซเคิล

เว็บค้นหาธาตุปีศาจและจัดการรายชื่อสำหรับกิลด์ สร้างด้วย TypeScript, Vite และ Supabase

## ปีศาจประจำวัน

- ผู้ใช้ทุกคนดูรายชื่อของวันนี้ได้
- ผู้ดูแลเพิ่มได้สูงสุด 5 ตัวต่อวัน
- วันใหม่เริ่มเวลา 00:00 น. ตามเขตเวลา `Asia/Bangkok` โดยข้อมูลวันเก่ายังถูกเก็บไว้
- แสดงเวลาไทยและเวลานับถอยหลังถึงเที่ยงคืนแบบวินาทีต่อวินาที พร้อมเปลี่ยนเป็นรายการวันใหม่ทันที
- ช่องชื่อค้นหาคำตรงกลางได้และหน่วงคำแนะนำ 240 ms
- ชื่อที่ขึ้นต้นด้วย `ปีศาจ` จะถูกตัดคำนำหน้าออกก่อนค้นหาและบันทึก
- ชื่อเดิมใช้ธาตุเดิมอัตโนมัติ ส่วนชื่อใหม่ต้องเลือกธาตุก่อนบันทึก
- รายการที่เลือกจากคำแนะนำลบได้อย่างเดียว ส่วนปีศาจที่สร้างใหม่จึงจะแก้ไขได้
- เมื่อเลือกคำแนะนำ ระบบเพิ่มเข้าช่องปัจจุบันทันทีและย้ายไปช่องถัดไปโดยไม่ต้องกดปุ่มเพิ่ม

## เปิดใช้กับ Supabase

โปรเจกต์ที่มีตาราง `demons` อยู่แล้ว ให้รันไฟล์ `supabase/daily-demons.sql` หนึ่งครั้งใน Supabase SQL Editor

โปรเจกต์ใหม่สามารถรัน `supabase/schema.sql` แล้วตามด้วย `supabase/seed.sql`

ไฟล์ frontend ใช้เฉพาะ Supabase publishable key เท่านั้น สิทธิ์เขียนข้อมูลถูกบังคับด้วย Row Level Security

## คำสั่งพัฒนา

```bash
npm install
npm run dev
npm run build
```
